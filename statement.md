# Gym Membership Management System

## Problem Statement

Managing gym membership records manually can make it difficult to register members, search records, manage membership information, handle deletions, and organize member-related operations efficiently. The Gym Membership Management System provides a command-line based solution for managing gym member records using Java and data structures.

The system allows users to register and manage members, search member records, update member status, perform sorting and searching operations, manage trainer waiting queues, and maintain referral information.

## Scope of the Project

The project focuses on managing gym membership information through a command-line interface. It provides operations for:

- Registering new gym members
- Viewing and searching member records
- Removing member records
- Updating member status
- Sorting member records
- Managing trainer waiting queues
- Managing referral relationships
- Saving member information to a MySQL database

The project demonstrates the practical application of data structures and algorithms in a real-world management system.

## Target Users

The system is intended for:

- Gym administrators
- Gym reception or front-desk staff
- Gym membership management personnel

## High-Level Features

- Member registration and record management
- Member search and lookup
- Member deletion
- Active/Inactive member status management
- Undo operation using a stack
- Trainer waiting queue management
- Member sorting
- Tree-based member organization
- Referral graph traversal
- Hash-based member lookup
- MySQL database persistence
- Command-line based interaction
